# Ameer Shameel

Jag utbildar mig inom **frontendutveckling med databaser** och studerar **cybersäkerhet på egen hand**. Jag gillar att följa ett användarflöde hela vägen, från det som syns på skärmen till API:et och databasen bakom.

Jag vill bygga säkra, robusta och genomtänkta lösningar. I biografprojektet blev det väldigt konkret. Vad händer om två personer försöker boka samma stol samtidigt? I Marginalia ställde jag en annan fråga. Hur ser jag till att varje användare bara kommer åt sina egna böcker?
